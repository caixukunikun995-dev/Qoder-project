# CS Rush

> 轻量战术射击网页小游戏 · 借鉴 CS2 玩法与蓝洞 POBG「维护时即点即玩」的形式 · **Qoder 高校创造力大赛参赛作品**

2D 俯视像素风、**单人 + 机器人**的经典**爆破模式**。免安装、发链接即玩，适合作为维护停机时的轻量小游戏。

当前版本 **v0.20**（版本与迭代日志见游戏内「关于游戏」页，源码 `src/version.js`）。

## 界面与流程

- 主菜单：**开始匹配 / 关于游戏 / 退出游戏**。
- 开始匹配 → 选择地图与赛制 → **匹配动画（随机 3–23 秒）** → **加载界面** → 对局。
- 半场换边 + 手枪局；比分平局（6:6 / 12:12）弹出**加时询问**：是 → $16000 + 换边继续；否 → 结束菜单。
- 结束菜单：**开始匹配**（同地图再战）/ **退出游戏**。
- 关于游戏：背景模糊，展示制作人员、版本与迭代日志。
- HUD 复刻 CS2 布局：雷达左上（仅显示我方视野内敌人）、生命/护甲/金钱左下、武器/弹药/投掷物右下、顶栏比分+双方存活队员（名字+血量）、击杀播报右上；回合结算 CS2 横幅+MVP、比赛结束 CS2 记分板。

## 赛制与经济（CS2 1:1）

- 赛制可选 **MR6（先 7）/ MR12（先 13）**；半场换边；加时 MR3、$16000、换边。
- 开局 / 半场 / 加时首局为**手枪局**（$800）。
- 经济：胜 $3250（引爆/拆包 $3500）、连败补偿 $1400→$3400、击杀按武器类别、下包/拆包 +$300、上限 $16000。
- 购买菜单按参考图复刻 5 列（装备/手枪/中级/步枪/投掷物），**T 与 CT 枪械不同**；投掷物 G 投掷 / H 切换。

## 分辨率自适应

启动时按窗口尺寸适配画布，并**每 5 秒**检测窗口变化自动重排（另监听 resize 即时响应）。v0.14 起低 DPR 屏启用 SSAA 超采样抗锯齿。

## 玩法

- 你扮演 **CT（防守方）**，与 2 名 CT 队友一起对抗 3 名 **T 机器人**。
- 目标：阻止 T 在 A/B 包点下包，或在炸弹安放后将其拆除；也可全灭对方。
- **回合制**，先赢 **5 回合**夺冠。每回合流程：购买 → 冻结 → 交战 → 结算。
- **经济系统**：按胜负 / 击杀 / 下包 / 拆包获得金钱，用于购买武器与装备。
- 武器：手枪（免费）、冲锋枪、步枪、狙击枪；装备：护甲、头盔、拆弹器。
- 失败条件：CT 全灭、炸弹引爆、或回合时间耗尽（未下包时判 CT 胜）。

## 本地运行

ES 模块不能以 `file://` 直接打开，需要任意静态服务器：

```bash
# 方式一：Python（无需安装依赖）
python -m http.server 8000
# 打开 http://localhost:8000

# 方式二：Node
npx serve .

# 方式三：VS Code 安装 "Live Server" 扩展，右键 index.html → Open with Live Server
```

## 部署到 GitHub Pages

仓库 **Settings → Pages → Build and deployment** 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 技术栈

原生 **JavaScript (ES Modules) + Canvas 2D + WebAudio**，零依赖、免构建。v0.14 起采用**等距 45°（2:1 diamond）投影**重渲染地图与实体（真 diamond tiles + 高度挤出 + 左/右面方向光 + 深度排序），叠加 bloom 泛光、SSAA、粒子、软阴影与暗角/方向光后期；音效全部由 WebAudio 程序化合成。角色为原创 operator 造型（非 Valve 模型），4 帧步态 + 身体 bob。

## 三人分工建议

- **A · 引擎 / 渲染**：`src/engine/`、主循环、相机、碰撞、性能。

- **C · 美术 / UI / 地图 / 音效**：`src/ui/`、`src/world/`、标题与视觉打磨。
